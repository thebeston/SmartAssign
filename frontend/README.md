# SmartAssign Frontend

Angular frontend for the SmartAssign task API.

## Run

```bash
npm install
npm start
```

App runs on `http://localhost:4200`.

## Backend Connection

The frontend calls `/tasks` endpoints and expects the backend API to be available on `http://localhost:8080` via proxy configuration.

## Available Scripts

- `npm start`: run dev server
- `npm run build`: create production build
- `npm test`: run unit tests
